Multi-Page Responsive Portfolio Built with AI-Assisted Vibe Coding

Course: ISDS 3100
Timeline: Spring 2026
Role: Front-End Developer & Designer
HTML5 CSS3 Responsive Layout Vibe Coding Git / GitHub

Project Overview

The objective of this project was to establish a professional digital presence by engineering a clean, accessible, and modular multi-page website. Leveraging AI-assisted development tools (vibe coding), the focus was on iterating rapidly, writing maintainable semantic HTML, and establishing a unified CSS design system.

Key Highlights & Features

  • Unified Styling: Centralized design tokens and reusable classes via a single external stylesheet ([styles.css](styles.css)).
  • Responsive Grid & Flexbox: Mobile-first adaptability across smartphones, tablets, and desktop displays.
  • Semantic HTML5 Architecture: Enhanced accessibility and SEO using header, nav, main, section, and footer elements.
  • Seamless Inter-page Navigation: Active page state indicators allowing effortless navigation across all views.

Key Learnings & Next Steps

Through this project, I gained practical hands-on experience combining business systems analysis with modern web design:

  • Mastered collaborative pair programming with AI agents to structure boilerplate quickly and eliminate repetitive syntax work.
  • Learned the importance of modular CSS architecture to keep styles clean, DRY (Don't Repeat Yourself), and easy to extend.
  • Next Steps: Integrate interactive JavaScript features (such as dynamic project filters and a functional contact form).
