Reflection

One thing I did not understand at first was how CSS media queries worked. I asked the AI agent to explain why `@media (max-width: 600px)` was being added to my CSS. I learned that a media query allows the website's design to change based on the size of the user's screen. This helped me understand how to make my website display better on both computers and mobile devices.
